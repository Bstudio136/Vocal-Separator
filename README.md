A powerful, futuristic AI graphical interface to separate vocals and instruments from any audio track. Built with a sleek Cyberpunk/Quantum theme, it uses Meta's Demucs AI engine to extract high-quality stems directly to your computer.

### 📸 Preview
*(Add a screenshot of your app here later by dragging and dropping an image)*

### ✨ Features
*   **🧠 AI Neural Separation**: Uses Demucs (by Meta) for state-of-the-art vocal isolation.
*   **🎛️ Quantum UI**: Fully animated interface with neon lasers, rainbow text, and dynamic glows.
*   **🎵 Flexible Output**: Export extracted stems as high-quality MP3 (320k) or Lossless WAV.
*   **⚡ Real-Time Terminal**: Watch the AI processing happen live in the built-in console.
*   **🔗 Clickable Signature**: Custom built-in link to the developer's profile.

### 🚀 Quick Start & Installation

**1. Clone the repository:**
```bash
git clone https://github.com/Bstudio136/Vocal-Separator.git
cd Vocal-Separator
```

**2. Install dependencies:**
```bash
pip install customtkinter demucs
```

**3. Run the application:**
```bash
python vocal_separator.py
```

### ⚠️ Important Note
You **must** have **FFmpeg** installed on your system for Demucs to process audio and for MP3 conversion.
*   **Windows**: `winget install ffmpeg`
*   **macOS**: `brew install ffmpeg`
*   **Linux**: `sudo apt install ffmpeg`
